# Verity

Privacy-first KYC/KYB frontend prototype with role-based workspaces for customers, businesses, bank operations, compliance, auditors, and platform administrators. Built with Next.js, TypeScript, and Tailwind CSS.

The demo uses synthetic data and simulated authentication. It does not connect to a production backend or identity provider.

## Run locally

```powershell
npm install
npm run dev
```

Open http://localhost:3000/demo to preview all role dashboards, or http://localhost:3000/login to enter a role workspace. The demo MFA code is `246810`.

## Build

```powershell
npm run build
```
